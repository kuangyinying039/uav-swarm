# 第一部分　逐页技术原理与逻辑讲解

## 第1页　封面

本页是汇报入口，不承载技术细节，但决定老师对题目边界的第一印象。

【内容要点】题目为“基于多智能体强化学习的无人机协同追逃方法研究”，汇报人匡银滢，日期2026年11月11日。

【逻辑作用】明确三条主线：多智能体（不是单机跟踪）、强化学习（但后面会看到是“教师热启动 + 在线微调”而非纯从零探索）、无人机协同追逃（双机捕获、遮挡感知、Sim2Real）。组会开头可一句话点题：问题是三维遮挡下的双机协同捕获；方法是MARL，但用MPC教师与O2O约束把样本效率与稳定性做实；目标是可向PX4迁移。

## 第2页　背景与意义：随机马尔可夫博弈与方法动机

【技术原理】追逃系统（PES）中，多架无人机追逐一架逃逸机。多智能体交互可建模为随机马尔可夫博弈（Stochastic Markov Game）：每架追击机是智能体，联合状态转移依赖全体动作与环境随机性（遮挡、探测概率、动力学噪声）；收益与是否形成团队捕获相关。与单智能体MDP相比，关键多了非平稳性：同伴策略变化时，本机面对的环境也在变。

【场景逻辑（图示）】左图给出三维城市几何：三架追捕机P1–P3、逃逸机E、建筑物、捕获半径约1 m。右图强调水平投影上的有限感知（Mid-360式360°视场、量程）、建筑LOS遮挡、同伴间可共享航迹消息。逃逸策略倾向“找遮挡”。

【问题链条】传统规则方法（APF、PN类、手工协同几何）依赖人工设计，对动态目标与复杂遮挡适应有限 → 强化学习可从交互学习 → 但RL本身有训练不稳定、样本效率低、策略易遗忘等问题。因此后文不是“扔掉规则”，而是“教师 + RL + 约束”，这是全篇方法学立场。

## 第3页　三个核心研究问题与任务定义

【三个问题对应三个能力】（1）协同策略：单机靠近≠团队成功。成功条件是至少两架仍有效的追击机同时进入捕获半径 → 关键词“团队捕获能力”。（2）不完整感知：策略不能读仿真真值，只能用本地雷达量测与融合航迹 → “环境适应力/可部署观测接口”。（3）真机接口：连续动作、运动响应、状态估计与PX4一致 → Sim2Real。

【任务契约（后面实验都挂在这上面）】3追1逃；三维、建筑遮挡、有限感知、连续控制；捕获为双机进入规定半径；逃逸方考虑追击位置、安全距离与遮挡选机动。这一页是“成功判据与观测约束”的法理依据，结果表里的capture rate必须按此理解。

## 第4页　追逃环境、PhysX/Lee链路与总体Pipeline

【物理与控制链路】平台Isaac Sim 4.1；决策周期dt=0.2 s（5 Hz）。机体参考Hummingbird量级参数。推进由PhysX关节体+旋翼力完成；上层策略只发速度类指令，经Lee几何控制器变成四路油门。策略动作是归一化四维 a∈[-1,1]^4（ax,ay,az,aψ），再映射为水平/垂直速度与偏航率，并注意ENU/NED等坐标约定。

【双机捕获规则】N_close ≥ k（k=2），且每架进入半径的距离判据 di≤1（三维距离）。这决定奖励里必须有“第二近距离/团队势”，不能只优化单机距离。

【Pipeline逻辑】任务与环境 → 示范数据 → 策略初始化 → 强化学习 → 评测与迁移。整条链强调：先有可迁移接口与教师，再RL，再评测/真机。

## 第5页　双机捕获几何与安全间距

【几何原理】捕获球半径R=1.0 m；同时要求机间安全距离≳0.8 m。若两机都在球面上，弦长 ‖p1-p2‖=2R sin(θ/2)，由 ‖p1-p2‖≥0.8 得 θ≳2 arcsin(0.4)≈47.2°。越靠近球心，同样安全间距所需张角更大。

【对方法的含义】（1）奖励/教师目标不能鼓励两机重叠贴目标；（2）“一近一稍远/错开方位”是几何上合法的双机构型；（3）P3可在外策应，但成功只需任意两架满足条件。此页把“团队势函数/MPC双机目标”的几何动机钉死。

## 第6页　相关工作框架对照（课程学习 / 预测增强 / SERL）

本页是文献与工程框架对照，说明社区常见做法：（1）多UAV追逃的双重课程学习：内参课程（半径、速度）+外环境生成/域随机化，再部署；（2）未知环境在线规划：SysID对齐动力学，逃逸预测网络+Actor-Critic；（3）SERL：Actor采集与Learner训练解耦，提高样本效率。

【与本文关系】你走的是另一条“强教师热启动 + O2O防崩塌 + 可部署观测”路线，而不是单纯课程或纯在线探索。此页用来向老师表明：问题领域有成熟脉络，你的贡献点在协同双捕获、航迹接口、PBRS、HGAT与O2O约束的组合。

## 第7页　总体设计思路：教师→模仿→在线 + 协方差交叉

【为什么不能从零学】捕获是稀疏终端事件；观测是遮挡与延迟航迹；动作连续；且已有强教师（MPC等）。从零探索样本效率极差。

【六步设计】1）真值换成可部署航迹，策略与教师同接口；2）折扣一致的势函数把靠近/双机到位/可见变成稠密信号（PBRS）；3）HGAT表达自己、航迹、同伴、建筑；4）BC+DAgger得到π0；5）在线用演员锚点、参考KL、成功回放等限制偏离；6）网络与经典教师再混合：a=clip((1-w)a_MPC + w a_RL, -1,1)。

【航迹融合】各机常速KF得本地航迹；邻居相关程度未知时，用协方差交叉（CI）保守融合：ω* = arg max log det(ω P1^{-1}+(1-ω)P2^{-1})，再合成信息矩阵。避免相关噪声下的过度自信，是“不读真值仍能协同”的关键。

## 第8页　奖励函数：个体/团队/可见/安全

【结构】R = 个体接近势差分 + 双机团队势差分 + 可见性势差分 + 有界安全与平滑代价。

【个体】Φ_i = exp(-max(d_i-R,0)/12)，入球后饱和为1；rind = 2·mean(γΦ'−Φ)。饱和抑制“贴脸刷分”。

【团队】g^{(2)}=max(d_{(2)}-R,0)（第二近距离超额），Φ_gap=exp(-g^{(2)}/12)，rgap=4(γΦ'−Φ)。直接对齐双机成功判据。

【可见】Φ_vis=1_team + 0.5·ratio，鼓励至少一人盯住并提高多人可见，服务遮挡交接。

【安全平滑】贴楼、边界、机间、指令平滑、急停拒绝、安全改写等惩罚，迫使策略发出“飞得过去”的指令，而不是依赖安全层硬改。

逻辑：稀疏捕获 → 势差分塑形；团队项权重通常高于个体，防止单机英雄主义。

## 第9页　PBRS势差分：为什么这样塑形合法

【核心公式】r_shape = γΦ(s') − Φ(s)。

【与直接距离奖励对比】普通逐步距离奖励容易改变最优策略（例如原地刷近距离）；PBRS在标准条件下不改变最优策略（Ng et al., 1999）。终端势置0避免拖到结束刷分；入球饱和避免无效贴脸。

【文献脉络】从单智能体策略不变性，到多智能体Nash扩展、动态势、内在动机转化，再到近年离线MARL与学习势函数——此页说明你的塑形不是拍脑袋，而是有理论谱系。组会可强调：你用的是手工几何势，未来计划再用HGAT学势参数。

## 第10–11页　异构图注意力编码器（HGAT）与策略头

【问题】定长MLP拼接会混淆“楼/队友/航迹”语义，变长实体也不好处理。

【HGAT逻辑】（1）构图：Self / Target / Peer / Building；Self投影为h^{(0)}作为Query源。（2）UAV–UAV多头注意力：通信邻接+相对几何进入边偏置e_ij，多头聚合同伴消息。（3）实体注意力：对航迹、建筑等异质实体用不同投影与注意力。（4）语义门融合：对tgt/peer/bldg消息打分softmax加权。（5）残差+LayerNorm，失能机清零掩码。（6）策略头输出4维动作再clip到[-1,1]，映射为速度与偏航率。

【分布式决策】每架机只看本机局部异构图，输出本机动作——与“局部雷达+有限通信”一致，也便于真机部署。

## 第12页　教师MPC、行为克隆与DAgger

【教师MPC（经典版，与代码一致）】用航迹外推预测点；最近2架拦截、第3架侧翼。每机不在连续空间解最优控制，而在约11个速度候选中选：J(v)=3‖p+v·1.6−g‖² + 0.25‖v−v_prev‖² + 分离项 + 建筑项。这是离散枚举式运动学制导MPC，不是CasADi/acados类连续NMPC。

【BC】只训Actor，让tanh μ贴近教师动作；另有小权重回归截断前均值。现象：BC约0.475 → 某一轮升到0.575 → 再崩到0.35，典型分布偏移。

【DAgger】第k轮以β_k概率用MPC开飞机，否则用当前网络；β衰减。把网络真实会到达的状态纳入数据集，并标注教师动作，缓解covariate shift。得到的π0是后续O2O的锚。

## 第13页　抑制Offline-to-Online崩塌（MATD3与MAPPO）

【病症】离线模仿后直接开RL，策略易被错误Q或过大更新拉离π0，捕获率崩塌。

【MATD3侧】小噪声探索退火；损失=RL + w_demo·BC + w_anc·锚点回归；TD3+BC式λ=α/|Q|缩放RL项；混合批量BC；截断bootstrap回报上界；成功回放等。

【MAPPO侧】PPO损失上加演示BC权重退火；KL惩罚离开冻结π0；收紧clip（如0.92–1.08）；解析高斯KL监控；按捕获率回滚。

【共同点】“先离线模仿，再在线RL，但用约束把热启动保住”。这是你相对纯RL叙事最需要讲清楚的工程贡献。

## 第14页　Sim2Real对齐清单

五条对齐保证“仿真策略≈真机可调用函数”：1）动作：vx,vy,vz与偏航率；ENU↔NED轴变换；2）观测：禁止真值，影子环境填里程计与外部航迹，调用同一observe_search()；3）感知：几何Mid-360视场/量程/建筑遮挡；4）动力学：PhysX闭环+Lee跟踪；5）两层安全：仿真内改写并惩罚；真机独立过滤（里程计超时、过近、高度/围栏）置零悬停。

迁移阶梯：单机速度跟踪→双机相对定位→静止合围→慢速逃逸→完整对抗。体现风险递进，不是一步上对抗。

## 第15页　Isaac仿真结果表（运动学 vs 纯PhysX闭环）

【读表方法】N/M/H/S/E为难度阶梯上的捕获率。左表偏运动学/较早设定，右表为纯物理闭环。

【关键观察（与你组会叙事一致）】- APF很弱；FRPN在运动学表上很强，闭环后明显下降——呼应后文“为何逃逸运动学时有效、闭环失效”。- 经典MPC在闭环上仍是很强的教师地板（如N≈0.675, H≈0.505）。- 学习方法与MPC/FRPN混合的结果需看是否超过教师、是否在高难度更稳。- π0（模仿初始化）本身已有一定能力，但通常低于强MPC地板；O2O与混合权重决定能否稳住并提升。

讲解时建议主动区分两张表的仿真契约，避免被问“为什么两边数字不可比”。

## 第16页　混合权重扫描与消融

【混合测试】MAPPO/MATD3与教师按RL比例w混合：a=(1-w)a_base+w a_RL。常见现象：中等w（如0.25–0.5）在部分难度上可超过纯教师或纯RL；w→1（纯RL）不一定最好；MATD3高w时某些档掉得更凶——说明“超越教师”不能简单把w拉满，而要看算法是否真正学会互补残差/协同。

【消融】对比MATD3-MPC与MAPPO-MPC等，回答“算法骨干差在哪里、教师绑定差在哪里”。此页是结果分析的核心论证页：混合是推理时的凸组合，也是训练期残差课程的镜像。

## 第17页　难点思考与未来计划

【自我提问（很适合组会讨论）】主仿真环境口径（大范围 vs 0.9&0.3等）如何统一？为何FRPN运动学有效闭环失效？如何从理论上超越教师？BC+DAgger有无结构性问题？现在是否“不够强化学习”？

# 第二部分　专家视角提问与得体答复（20题）

以下问题按“问题定义 / 方法机理 / 实验可信度 / 与教师关系 / 落地”组织。答复语气：承认边界、给出机制、指向证据页、不争辩、可承诺后续验证。

Q1. 你把问题建成随机马尔可夫博弈，和普通多智能体MDP有何本质不同？合作还是竞争？

答：本质不同在于：每个追击智能体的转移与回报同时依赖同伴动作，环境对单智能体是非平稳的；逃逸方若策略固定或规则化，则对追击团队可视为部分外生非平稳扰动。我们当前优化的是追击团队的协同捕获，属于团队合作式目标，逃逸方作为对手规则/环境动力学存在，而不是与逃逸方做联合均衡求解。若后续逃逸也学习，才更接近完整零和/一般和随机博弈设定。

Q2. 双机捕获为什么比单机进入半径更合理？会不会把问题人为做难？

答：单机半径捕获在遮挡城市里容易退化成“谁先撞上算谁”，无法体现协同围堵与交接。双机捕获要求第二近距离也进入球，并与安全间距共同约束构型，这与任务语义一致。难度上升是有意的：它倒逼团队势、教师角色分配与HGAT协同表征，而不是把单机跟踪包装成多智能体。

Q3. 策略不看真值只看航迹，估计误差大时会不会学到错误策略？

答：训练与部署用同一observe接口，避免sim中偷看真值造成的不可迁移捷径。航迹侧用常速KF+协方差交叉，宁可保守也不过度自信。奖励里的可见性项鼓励保持可观测，减少“瞎猜冲刺”。当然估计偏差仍会伤害性能，所以结果应解读为“在该感知契约下的捕获率”，我们也把感知对齐列入Sim2Real清单。

Q4. 你们的MPC教师到底是不是真正的最优控制？线性还是非线性？

答：汇报中的经典MPC教师是运动学层的离散候选制导：用常速外推预测点，在约11个速度候选上枚举代价（终端距离、平滑、分离、建筑），不是CasADi/acados一类连续时间非线性规划，也不是线性二次MPC的解析Riccati解。它强在可复现、快、能提供双机几何角色，弱在最优性没有连续优化保证。我们正把它作为强基线/教师地板，并另研更严格的非线性运动学NMPC作对照。

Q5. 既有强MPC，为什么还要强化学习？会不会只是在模仿？

答：MPC受局部模型、离散候选与感知噪声限制，难覆盖全部遮挡与多机协调模态；RL理论上可在同接口上继续改进。我们的路径是BC+DAgger得到π0，再O2O微调，并用混合权重扫描看是否在部分难度超过教师。若最终只能逼近教师，说明教师天花板高或塑形/探索不足——这正是第17页要讨论的“如何超越教师”。

Q6. PBRS保证不改变最优策略，但你们势函数是手工设计的，如何保证多机情形仍成立？

答：经典PBRS理论源于单智能体；多智能体有Devlin、Lu等对Nash/一般和博弈的扩展，但前提与势的可分解性有关。我们采用个体势+团队势+可见势的加性结构，并保持γ与环境一致、终端势处理谨慎，这是工程上对齐文献精神。严格证明当前势不改变团队均衡超出本组会范围；实验上用消融与捕获率验证塑形是否提升样本效率而非扭曲成功判据。

Q7. 团队势用第二近距离，为什么不直接对捕获成功给大稀疏奖励？

答：成功事件极稀疏，纯终端奖励在5 Hz、数百步回合里几乎学不到。第二近距离势把“还差多少形成双机球”变成逐步可导的进度，且与成功定义一致。个体势与团队势并存，是为了既有靠近动机又有协同动机；权重上团队项更大，抑制单机刷分。

Q8. HGAT相比普通GAT或Transformer多在哪里？算力开销如何？

答：普通拼接MLP或缺省GAT难以区分peer/target/building异质关系。HGAT用不同关系投影、边几何偏置与语义门融合，更贴合“局部雷达图”。开销高于扁平MLP，但决策仅5 Hz、机数=3，在线推理可接受；训练侧相对仿真步进通常不是主瓶颈。若老师关注实时性，可补充单步推理耗时与机载算力预算。

Q9. DAgger需要反复问教师，在线阶段算不算仍依赖MPC？部署还要不要教师？

答：DAgger主要用于离线构造π0。部署可以纯策略，也可以按需凸组合教师（混合推理）。训练期O2O的BC/锚点是对冻结π0的约束，不一定在线调用MPC。我们在结果中同时报告纯策略与不同w混合，以区分“可独立部署的策略能力”和“教师辅助推理”。

Q10. 第13页O2O约束很多，会不会把RL优化空间锁死，学不到新行为？

答：这是权衡：约束过强→接近模仿；过弱→崩塌。我们用权重退火（BC/锚点随时间下降）、成功回放与捕获率回滚，力图在“不崩”的前提下逐步放开。混合扫描里中等w有时优于两端，说明存在互补空间。若捕获率长期贴教师不上，应减弱锚点或改进势/探索，而不是加更多锁。

Q11. MATD3与MAPPO为何双线？主推哪一个？

答：MAPPO是on-policy、易加KL/clip约束，适合守住π0；MATD3是off-policy、样本复用强，适合示范回放与O2O。双线是对照而非骑墙：看谁在物理闭环与混合设定下更稳。汇报主线可表述为“以可部署接口+教师热启动为共同底座，对比on/off-policy两条骨干”。

Q12. 左表FRPN很强、右表变弱，如何解释？是否说明实验不稳定？

答：更可能是仿真契约变化：运动学/简化逃逸响应 vs PhysX闭环+Lee跟踪时，逃逸与追捕的相对机动与姿态/延迟特性变了，依赖精确几何导引的FRPN更敏感。这不是随机抖一下，而是“模型失配暴露基线脆弱性”。我们也因此把PhysX闭环作为更接近真机的主评测。

Q13. 你们如何证明提升来自算法而不是超参或随机种子？

答：固定难度阶梯、种子段与捕获定义；报告多档捕获率而非单点；做教师混合权重扫描与算法消融；关键结论看趋势是否跨档一致。若老师要求更严，可补充多种子置信区间与统计检验，这是后续完善项。

Q14. capture rate到0.5左右，工程上是否够用？论文贡献如何定位？

答：在双机捕获+遮挡+不看真值的契约下，0.5量级说明任务硬、教师也未饱和。贡献宜定位为：可部署观测与控制接口、双机几何对齐的奖励/教师、以及O2O防崩塌的训练流程，而不是宣称已解决追逃。后续超越教师与Sim2Real验证才是能力跃迁。

Q15. 安全层改写动作，会不会导致策略把责任甩给安全层？

答：会，所以奖励显式惩罚急停/改写/不可行指令，促使网络输出本身可行的速度。真机再加独立硬约束是冗余安全，不替代训练目标。评估时也可统计安全干预率，作为策略质量辅助指标。

Q16. Sim2Real列了五条对齐，目前真机验证到哪一步？

答：目前工作重心在Isaac PhysX闭环与接口对齐；真机阶梯按“单机跟踪→相对定位→静止合围→慢速逃逸→对抗”推进。组会可如实说已完成的仿真对齐与待飞的阶梯，避免暗示已经全流程实飞对抗。

Q17. 如果MPC教师错了，DAgger会不会系统性强化错误？

答：会有教师偏差上限。缓解：成功回放与捕获率导向的在线目标、混合时保留探索、未来用更好NMPC/多教师、以及对失败态的数据分析。DAgger保证的是“状态分布覆盖”，不自动保证教师全局最优。

Q18. 连续动作空间为何不用SAC等更现代的off-policy方法？

答：我们选MATD3是因其与示范BC、双Q截断、延迟策略更新的工程组合成熟，且与现有代码/实验栈一致。SAC的熵项与温度调节对O2O锚点约束的交互需另做稳定化。这是实现选型，不是否定SAC；可作为后续对照。

Q19. 多机决策是CTDE还是完全分布式？训练时有没有中心化批评家偷看全局？

答：执行侧强调分布式：局部图→本机动作。训练侧MAPPO/MATD3通常可用中心化价值/团队批评家（CTDE）稳定信用分配，但这不意味着执行依赖全局真值。需向老师区分：训练可中心化，执行与观测仍遵守局部航迹契约。

Q20. 你认为当前工作最容易被质疑的一点是什么？下一步最优先做什么？

答：最容易被质疑的是：相对强教师的净提升是否稳定、以及运动学表与闭环表的叙事是否足够干净。下一步优先：（1）统一主评测口径到PhysX闭环；（2）用更严格NMPC与消融把教师/算法贡献拆开；（3）把双机几何可行域进一步写入势函数；（4）按Sim2Real阶梯做最小可飞验证。
